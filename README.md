# Mosi Table — Zambian Restaurant Portfolio

Responsive multi-page HTML/CSS/JavaScript website concept for a contemporary Zambian kitchen.

- `index.html`: editorial homepage and brand introduction
- `menu.html`: filterable sample menu
- `story.html`: brand story with original CSS artwork
- `visit.html`: visit details and interactive demo booking request form

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Notes
- Shared styles: `assets/css/style.css`; interactions: `assets/js/main.js`.
- Food photography only on the homepage; no generic lifestyle photos. Replace image URLs with licensed restaurant-owned food photography before commercial launch.
- Menu items and prices are illustrative. Mosi Table is a portfolio concept, not a claim about an operating venue.
- The booking form is front-end only; it does not transmit or store data.
- Google Fonts and food photography require an internet connection.
